# Values by group

Every item in a group gets the same values.

| **Column** | **Support** | **Training** | **License** |
|---|---|---|---|
| **Department** | None for now | None for now | None for now |
| **Class** | Support | Training | License |
| **Income account** | 41200 Support Revenue | 42200 Training Revenue | 41100 License Revenue |
| **Deferred Revenue account** | 23100 Deferred Revenue - ST | 23100 Deferred Revenue - ST | 23100 Deferred Revenue - ST |
| **Revenue Recogition Rule** | Blank: no rules set up yet | Blank | Blank |
| **Rev Rec Forecast Rule** | Blank: no rules set up yet | Blank | Blank |

Department, Class, accounts and rules must match existing NetSuite records, spelled as NetSuite shows them.
